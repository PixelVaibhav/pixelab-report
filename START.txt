1. Open this folder in VS Code (File > Open Folder).
2. Open .env and replace PASTE_YOUR_KEY_HERE with your Gemini API key. Save.
3. Open the terminal (Ctrl+`) and run, one at a time:
   py -3.12 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt -r requirements-dev.txt
   python -m pytest
   python -m uvicorn main:app --reload --port 8001
4. Open http://127.0.0.1:8001 in a browser.
Evaluation (separate from the website): python -m evaluation.run_eval
Next time, only run the Activate line and the uvicorn line.
